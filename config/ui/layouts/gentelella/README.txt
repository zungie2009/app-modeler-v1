Gentelella modern blueprint experiment

Add beside the already-tested layouts.

This experiment is deliberately self-contained and does NOT require Bootstrap.
It tests whether App Modeler's layout contract can support a polished modern UI
outside the Bootstrap family.

Acceptance test:
- CRM navigation
- module cards
- entity records
- UML
- Administration
- Apply & Interpret
- switch among existing layouts and back to gentelella

No Java changes required.
