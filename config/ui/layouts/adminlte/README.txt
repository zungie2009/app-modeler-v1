AdminLTE blueprint experiment

This folder is intended to be added beside the known-good `tabler` layout.

It preserves the proven App Modeler Vue/domain/menu/data contract while using a
distinct AdminLTE-style professional admin structure and CSS.

Test:
1. Restart App Modeler.
2. Select `adminlte` in Administration -> Layout.
3. Verify CRM menu, module cards, entity records, UML, Admin.
4. Click Apply & Interpret without changing anything.
5. Verify AdminLTE survives regeneration.
6. Switch to Tabler and back to AdminLTE.
